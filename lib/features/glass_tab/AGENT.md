# Glass tabs (Project360)

Pitch preview tabs use **`GlassTabShell`** with native **`CNTabBar`** from
`packages/cupertino_native` on iOS/macOS (Liquid Glass on iOS 26+ with Xcode 26),
and a gray capsule fallback on Android/web.

No handoff copy is required for the tab bar. Optional Vera iOS glue:

```bash
./tool/vendor_glass_tab.sh ~/Desktop/Cursor/vera_design
```

Vera Design screens: `./tool/vendor_vera_design.sh ~/Desktop/Cursor/vera_design`
